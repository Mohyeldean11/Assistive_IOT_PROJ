🔴 PIR sensor (HC-SR501) — detects infrared motion. Outputs digital HIGH when movement is sensed. Used to detect activity/inactivity windows. Connects to GPIO. Inactivity threshold logic (e.g., no motion for 10 min) triggers alert.
🆘 Emergency button — momentary push button wired between GPIO and GND. When pressed, Pi reads LOW → immediate cloud alert. Shows direct human-in-the-loop interaction, highly valued in academic demos.
🌡️ DHT22 — reads temperature (±0.5°C) and humidity (±2%). Adds environmental safety: alerts if temperature drops below safe threshold. Single-wire protocol, Adafruit_DHT library.
📷 Pi Camera v2 — optional but powerful. Motion-triggered JPEG capture and cloud upload. Use OpenCV for presence detection. Adds richer data pipeline for advanced reports.

🍓 Raspberry Pi 4 — runs Raspberry Pi OS Lite. Hosts Python scripts, connects to sensors via GPIO. Wi-Fi connectivity and Azure IoT SDK. 32GB microSD recommended.
🧠 Alert logic engine — Python module tracks last motion timestamp. Inactivity threshold (e.g., 10 min) triggers inactivity alert. Also handles button debounce and temperature range monitoring.
📦 Payload formatter — builds structured JSON messages. Example:
{"deviceId":"rpi-01","event":"inactivity","duration_min":12,"temp":21.5,"timestamp":"2025-04-10T09:12:00Z"}

🔐 MQTT over TLS (port 8883) — Azure IoT SDK handles TLS automatically. For advanced cybersecurity, upgrade to X.509 certificates instead of SAS keys.
🆔 Device authentication — each Pi is registered in Azure IoT Hub with unique device ID. SAS token per session ensures only registered devices publish telemetry — Zero Trust principle.
⚠️ Threat simulation — script that tries to connect with invalid device key. Azure rejects with 401. Log failed attempts and visualize on dashboard — powerful cybersecurity demo.

🌐 Azure IoT Hub (F1 free tier) — receives up to 8,000 messages/day. Authenticates identities, routes messages downstream. Built-in endpoint for basic version.
🗄️ Azure Table Storage — cheap and simple. Each telemetry message becomes a row (partition = deviceId, rowKey = timestamp). Blob storage for camera images if added.
⚡ Azure Logic Apps — no-code workflow that triggers on alert events (inactivity, button, temp). Sends email / Teams message. Fast setup for academic demos.

📈 Streamlit dashboard — Python-native, pulls from Azure Table Storage every few seconds. Shows sensor status, activity timeline, alert log, threat log. Deploy locally or on Streamlit Cloud.
🔑 Access control — minimal: st.secrets + password gate. Discuss RBAC conceptually (caregiver vs admin). Optionally use Azure AD B2C for token-based login.
📧 Notifications — caregiver receives email for: inactivity threshold, emergency button press, temperature out of range. Closes the assistive monitoring loop.

🐍 Python modules — Raspberry Pi (edge)
sensor_reader.py
GPIO polling loop for PIR, button, DHT22. Publishes events to internal queue. Runs as background thread.
alert_engine.py
Monitors inactivity timer, checks temp thresholds. Computes alert severity (info/warning/critical).
payload_builder.py
Builds JSON telemetry dict with deviceId, timestamp, event type, sensor values, alert flag.
azure_client.py
Wraps Azure IoT Hub SDK. Handles connection, reconnection, TLS message send using config.
config.py
Centralised settings: connection string, inactivity threshold, temp range, GPIO pin mapping. Never hardcode secrets.
main.py
Entry point. Starts sensor_reader thread, alert_engine loop, calls azure_client.send() on each event.
☁️ Python modules — Cloud side / dashboard
storage_writer.py
Azure Function (or script) that reads IoT Hub event stream and writes rows to Table Storage.
alert_notifier.py
Triggered on critical events. Sends email via SendGrid/SMTP, or POST to Teams webhook.
dashboard.py (Streamlit)
Queries Azure Table Storage. Shows live sensor status, activity timeline, alert log. Auto-refresh.
threat_sim.py
Simulates unauthorised device: attempts connection with invalid SAS key. Logs 401 rejection — cybersecurity demo.
